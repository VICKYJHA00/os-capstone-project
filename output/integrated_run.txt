SECTION 3 -- INTEGRATED SIMULATION (CPU scheduling linked to virtual memory)
==========================================================================
Every process owns a cyclic working set of 3 pages; each time unit
on the CPU it references the next page of that set.  The Gantt chart
of each scheduler therefore generates a different reference string.
Frames allocated: 4    Round Robin quantum: 4

Page assignment (working sets):
  P1 -> pages 1, 2, 3
  P2 -> pages 4, 5, 6
  P3 -> pages 7, 8, 9
  P4 -> pages 10, 11, 12
  P5 -> pages 13, 14, 15
